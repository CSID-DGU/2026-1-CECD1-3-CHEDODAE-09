# RAG 데이터

`rag-documents.json`은 INFODOG RAG 데모에서 사용하는 GitHub 공개용 익명화 코퍼스입니다.

- 원본 100마리 NGS 엑셀 데이터 전체를 익명화해 변환했습니다.
- 프로젝트 접근 방법, 데모 PHR/NGS 맥락, 식이 솔루션 근거, 익명 NGS 레코드를 포함합니다.
- 반려견 이름, 정확한 생년월일, 알러지원 원문, 치료 자유서술, 원본 행 번호는 제거했습니다.
- 질환군, 나이대, 체중대, 넓은 범주의 알러지/치료 카테고리, NGS 다양성 지표, 주요 균 정보는 유지했습니다.

원본 `.xlsx`, `.pdf`, 비익명화 RAG 생성 파일은 이 저장소에 커밋하지 않습니다.
